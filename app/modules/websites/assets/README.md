# Bundled sample photographs

These sample photographs are bundled so the template gallery and HTML exports do not rely on remote image services. A studio can replace them with its own images. ThemeForest demo code, logos, and paid theme assets are not included.

Sources (Unsplash image CDN, downloaded at 1200px, JPEG, quality 80):

- movement.jpg: https://images.unsplash.com/photo-1544367567-0f2fcb009e0b
- stillness.jpg: https://images.unsplash.com/photo-1506126613408-eca07ce68773
- sound.jpg: https://images.unsplash.com/photo-1511379938547-c1f69419868d
- learning.jpg: https://images.unsplash.com/photo-1503676260728-1c00da094a0b
- community.jpg: https://images.unsplash.com/photo-1509062522246-3755977927d7

Only these five local files can be selected as built-in sample images. Exports inline their bytes as data URIs. Existing Unsplash image URLs from older drafts can be imported through a constrained single-host downloader; new editors use uploads or these presets.
